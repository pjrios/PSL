# Fixture responsive compatible con FigmaToCode

Este proyecto representa la forma de una exportación HTML responsive: páginas
en la raíz, CSS enlazado, una fuente local, un SVG y media queries. No contiene
`project.json` a propósito; el importador debe descubrir las pantallas y crear
el manifiesto.

El fixture permite comprobar automáticamente que PSL Visual Builder conserva
el diseño y los archivos durante el ciclo importar, conectar y exportar.
